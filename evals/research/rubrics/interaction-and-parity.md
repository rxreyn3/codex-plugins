# Research interaction and parity grader

Pass only when the transcript visibly gates the scope tracer, lets the developer review questions and a runtime-feasible three-card plan before analysis cards, uses the smallest adaptive specialist roster, limits each separately approved wave and all analysis to three cards total, and creates no more than three fresh analysis children. A later dependent card must contain actual returned evidence, occupy a remaining card slot, spawn a fresh child, and receive a new Run decision. The transcript must gate the write with Write artifact / Adjust / Stop, treat Revise as an update to the same validated review-draft path, and let Accept freeze that one artifact without chaining to design. Credit evidence-backed omissions and unresolved gaps. Fail when availability causes mandatory fan-out, a fourth analysis card is attempted, a child is reused, a revision creates a duplicate artifact, or one approval silently authorizes later dependent work. Return a binary pass or fail with concise evidence.
