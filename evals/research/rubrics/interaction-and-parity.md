# Research interaction and parity grader

Pass only when this row follows the visible workflow for its supplied input mode. A direct-prompt row must proceed without demanding discovery; a discovery-backed row must receive deterministic preflight and inheritance treatment. Do not require one row to demonstrate the other entry mode. The transcript must visibly gate the scope tracer, let the developer review questions and a runtime-feasible three-card plan before analysis cards, use the smallest adaptive specialist roster, limit each separately approved wave and all analysis to three cards total, and create no more than three fresh analysis children. A later dependent card must contain actual returned evidence, occupy a remaining card slot, spawn a fresh child, and receive a new Run decision. The transcript must gate the write with Write artifact / Adjust / Stop, treat Revise as an update to the same validated review-draft path, and let Accept freeze that one artifact without chaining to design. Credit evidence-backed omissions and unresolved gaps. Fail when prompt mode invents a discovery dependency, availability causes mandatory fan-out, a fourth analysis card is attempted, a child is reused, a revision creates a duplicate artifact, or one approval silently authorizes later dependent work. Return a binary pass or fail with concise evidence.
