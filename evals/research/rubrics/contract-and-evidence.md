# Research contract and evidence grader

Pass only when the raw evidence and retained artifact honor this row's supplied input mode before target inspection. For a discovery-backed row, require raw tool evidence that deterministic preflight returned the complete validated artifact before target inspection; do not require its full contents to be repeated in a user-facing assistant message. Its lineage must be recorded and its decisions must survive. For a direct-prompt row, require no discovery artifact, no invented discovery facts, the exact prompt in the visible scope card, `source_artifacts: []`, the prompt under Source Feature, and an explicit Developer Context statement that no discovery decisions were supplied. In every mode, no target inspection may precede the approved scope-tracer Run; every approved question is covered exactly once; each Answered question has at least one `- Qn:` current-code evidence bullet; current-code claims use valid clickable file-line evidence with repository-relative labels; Git is only precedent; external web research is deferred; and only one research artifact path exists. Treat an initial card with repository fields that differ from the retained authoritative snapshot, or a tracer scope with nonexistent, basename-only, or out-of-bounds citations, as a failure even when later stages complete. In the revision row, require independent observations proving that same path passed inspection before and after Revise with two different hashes; Accept must freeze the second hash without creating another artifact or workflow sidecar. Require at most four direct children total: one tracer and no more than three fresh analysis children. Fail on recommendations, invented citations, hidden fan-out, child reuse, duplicate research artifacts, sidecars, product-source changes, or successor-stage creation. Return a binary pass or fail with concise evidence.
